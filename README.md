# TravelPlanner - AI 기반 맞춤형 여행 계획 앱

AI 기술을 활용한 개인 맞춤형 여행 계획 생성 및 관리 앱으로, 실시간 정보 업데이트와 최적화된 일정 관리를 제공합니다.

![TravelPlanner Logo](https://via.placeholder.com/150)

## 🚀 프로젝트 소개

TravelPlanner는 AI 기술을 활용하여 사용자 맞춤형 여행 계획을 자동으로 생성하고 관리하는 모바일 애플리케이션입니다. 개인의 선호도와 여행 스타일을 분석하여 최적화된 여행 일정을 제공하며, 실시간 정보 업데이트를 통해 더 스마트한 여행 경험을 선사합니다.

## ✨ 주요 기능

- **AI 기반 맞춤형 여행 계획**
  - 사용자 선호도 분석을 통한 개인화된 여행지 추천
  - 과거 여행 기록 기반 맞춤 추천
  - 계절별 최적화된 여행 계획

- **스마트 일정 관리**
  - Dijkstra 알고리즘 기반 최적 경로 계산
  - 실시간 교통 정보 반영
  - 이동 시간 최소화를 위한 동선 최적화

- **실시간 정보 업데이트**
  - 날씨, 교통, 영업시간 실시간 반영
  - 긴급 상황 알림
  - 대체 일정 자동 추천

- **스마트 예산 관리**
  - 카테고리별 예산 설정 및 추적
  - 실시간 지출 분석
  - 예산 초과 방지 알림

- **현지 활동 추천**
  - 지역별 특색 있는 활동 추천
  - 실시간 예약 시스템
  - 사용자 리뷰 기반 추천
