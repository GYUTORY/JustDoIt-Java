## 2. 불변 객체 개념 🎯

### 2.1 불변 객체란?
- 한번 생성되면 그 상태를 변경할 수 없는 객체
- Thread-safe하며 동시성 문제에서 자유로움
- 객체의 신뢰성과 안정성 보장

### 2.2 불변 객체의 특징
1. **필드의 불변성**
   - 모든 필드를 `final`로 선언
   - 필드에 대한 setter 메서드 제공하지 않음

2. **방어적 복사**
   - 가변 객체를 참조하는 경우 방어적 복사 사용
   - 생성자와 접근자에서 방어적 복사 구현

3. **안전한 공유**
   - 불변 객체는 자유롭게 공유 가능
   - 캐싱과 재사용이 용이
