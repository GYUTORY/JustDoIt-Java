# Java의 수학 클래스와 난수 생성 📐

## 1. Math 클래스 
Math 클래스는 수학 계산에 필요한 다양한 정적 메서드를 제공합니다.

### 1.1 기본 수학 연산
- **절대값 (abs)**
  - `Math.abs(-5)` → 5
  - 음수를 양수로 변환

- **올림/내림/반올림**
  - `Math.ceil(3.14)` → 4.0 (올림)
  - `Math.floor(3.14)` → 3.0 (내림)
  - `Math.round(3.14)` → 3 (반올림)

- **최대/최소**
  - `Math.max(a, b)`: 두 수 중 큰 값 반환
  - `Math.min(a, b)`: 두 수 중 작은 값 반환

### 1.2 지수와 로그
- **거듭제곱 (pow)**
  - `Math.pow(2, 3)` → 8.0 (2의 3제곱)
  - 첫 번째 인자의 두 번째 인자 제곱을 계산

- **제곱근 (sqrt)**
  - `Math.sqrt(9)` → 3.0
  - 숫자의 제곱근을 계산

- **자연로그 (log)**
  - `Math.log(Math.E)` → 1.0
  - 자연로그 계산

### 1.3 삼각함수
- **각도와 라디안**
  - `Math.PI`: 원주율(π) 상수
  - 각도를 라디안으로 변환: 각도 × (π/180)

- **주요 삼각함수**
  - `Math.sin(라디안)`: 사인값 계산
  - `Math.cos(라디안)`: 코사인값 계산
  - `Math.tan(라디안)`: 탄젠트값 계산

## 2. Random 클래스
난수를 생성하는 다양한 메서드를 제공하는 클래스입니다.

### 2.1 기본 사용법
```java
Random random = new Random();  // 시스템 시간을 시드로 사용
Random random = new Random(seed);  // 특정 시드값으로 초기화
```

### 2.2 난수 생성 메서드
- **정수형 난수**
  - `nextInt()`: 모든 int 범위
  - `nextInt(n)`: 0 이상 n 미만
  - `nextInt(start, end)`: start 이상 end 미만 (Java 17+)

- **실수형 난수**
  - `nextDouble()`: 0.0 이상 1.0 미만
  - `nextFloat()`: 0.0f 이상 1.0f 미만

- **불리언 난수**
  - `nextBoolean()`: true 또는 false

### 2.3 시드(Seed)의 특징
- 동일한 시드값을 사용하면 항상 같은 순서의 난수 생성
- 시드값을 지정하지 않으면 시스템 시간을 기반으로 자동 설정
- 테스트나 재현 가능한 결과가 필요할 때 유용

### 2.4 보안 관련 고려사항
- Random 클래스는 예측 가능한 난수 생성
- 보안이 중요한 경우 `SecureRandom` 클래스 사용 권장
- 암호화 키 생성 등에는 반드시 `SecureRandom` 사용
